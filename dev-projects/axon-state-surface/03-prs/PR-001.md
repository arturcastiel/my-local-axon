## Summary
Add two fields — `backup` and `plans` — to `cmd_menu_snapshot` (tools/axon_state.py), resolved
in-process from the my-axon local dir via the WRITER's own pointer (`_axon_paths.read_myaxon_pointer`
→ reader==writer, verified), following the tool's existing fail-soft convention. This removes the
omission that forced the menu render to hand-resolve those paths — the 2026-07-10 false
"not configured". Ships with fixture value-pinning (absolute assertions; a healthy fixture alone
would have caught the incident).

## Goal Context
Make it structurally impossible for a menu warning field to be rendered from an agent-guessed path;
warning fields resolve in code (the snapshot), never a hand-typed path. PR-001 supplies the
code-resolved source that PR-002's render consumes.

## Changes Required
### tools/axon_state.py — cmd_menu_snapshot (add fields before json.dumps @~:283)
- **What:** add `out["backup"]` (always-dict | None) and `out["plans"]` (dict | None).
- **How:**
  - Call-time import (mirrors the :84 `_default_workspace` idiom):
    `from _axon_paths import read_myaxon_pointer, default_myaxon`.
  - `myaxon = read_myaxon_pointer(args.workspace) or default_myaxon()` (verified never None →
    reader==writer, the same W:myaxon-path pointer the writer uses).
  - `local = Path(myaxon)/"memory"/"local"`. If `not local.is_dir()` → `out["backup"] = None`.
    Else **all-or-nothing** inside `try: … except Exception: out["backup"] = None`:
    read `myaxon-backup-{enabled,url,status,last-push}.md` (PIN `-last-push.md`, never `-last.md`),
    each = stripped text or None if that file is absent →
    `out["backup"] = {"enabled","url","status","last_push"}`. (Broad `except` because the existing
    `_read` catches only OSError — R4 from the risk study.)
  - `plans_dir = Path(myaxon)/"plans"`. If not a dir → `out["plans"] = None`. Else glob `*.md`
    (exclude INDEX.md); `active_count = count(files whose text contains "Status:  active")`
    (TWO-space substring — verified exact against the real plan files); `done_count = count(any of
    "Status:  complete","Status: complete","Status:  done","Status: done")`; `active_stems =
    sorted stems of the active files [:3]` → `out["plans"] = {active_count, done_count, active_stems}`.
  - Conventions: backup = always-dict-when-present (like drift/working_keys) — EXCLUDE from
    test_failed_probe; plans = whole-field-None on failure (like workflows).
- **Why:** authoritative single-call source for the two warning fields, via the writer's pointer
  (no path divergence). Additive — no existing consumer breaks.

### tests/test_menu_snapshot_*.py — fixture value-pinning (ABSOLUTE assertions, not self-parity)
- **What:** pin the snapshot dict values across states, controlling resolution by WRITING the pointer
  file `{ws}/memory/working/myaxon-path.md` → a temp my-axon (exercises the reader==writer path).
- **How / cases:** healthy(enabled="true",status="ok")→`backup.enabled=="true"`,`status=="ok"`;
  not-configured(local dir present, no enabled file)→`backup≠None`,`enabled is None`;
  push-error(status="error")→`status=="error"`; degraded(no local dir / read raises)→`backup is None`;
  path-canonicity→`-last-push.md` read, `-last.md` NOT; pointer-honored→snapshot reads the temp
  my-axon (reader==writer); plans→`active_count`/`done_count`/`active_stems` correct, `None` on missing dir.
- **Why:** a healthy fixture alone catches the 2026-07-10 false alarm; pins the contract PR-002 consumes.
